Example: jQuery

    - Designed to simplify HTML DOM tree traversals, manipulation

    - The features jQuery offers are now made available on
        - The core JavaScript APIs

    - Website (https://jquery.com/)

    - Integrated on a website the same way as the previous Lodash library
        - Using the HTML element <script>
