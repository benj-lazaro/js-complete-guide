Axios Library & HTTP Requests
-----------------------------
- Axios library is a Promise-based HTTP client for the browser & Node.js
    - A great ALTERNATIVE to "fetch()" API or XMLHttpRequest for HTTP requests

    - Importing the library via CDN
        - Using the HTML element <script>
        - Enables Axios to be globally available 
    
    - Offers methods named after HTTP requests
        - ".get()"      = Sends a HTTP request "GET"
        - ".post()"     = Sends a HTTP request "POST"
        - ".put()"      = Sends a HTTP request "PUT"
        - ".delete()"   = Sends a HTTP request "DELETE"

    - Eliminates the manual setup of HTTP headers
        - Axios automatically analyzes submitted data
        - Transforms submitted data accordingly (e.g. FormData, JSON, ...)
        - Chooses the appropriate "Content-Type" value

    - Better error handling on HTTP status code 400 or 500 (server-side)


- The method ".get()"
    - Requires one (1) argument value
        - API endpoint (URL) for HTTP request GET

    - Returns an Axios object that contains the property
        - ".data"       = ready-to-use parsed HTTP response body
        - ".headers"    = HTTP headers
        - ".status"     = HTTP request status code

    - In the event of HTTP status code 400 or 500
        - Successfully sent a HTTP request but encountered as server-side error
            - Axios throws an error 
        
        - Unlike using the "fetch()" API or XMLHttpRequest
            - Axios does NOT require extra work /code
            - To capture status code 400 or 500

        - NOTE: Details of the error is stored in "error.response"


- The method ".post()"
    - Requires two (2) argument values
        - API endpoint (URL) for HTTP request POST
        - Constant where the data to be submitted is stored

    - Automatically analyze the data submitted
        - Determines what data type to convert it into (e.g. JSON or FormData)
        - Set up the appropriate value for the HTTP header "Content-Type"

    - Returns an Axios object that contains the property
        - ".data"       = submitted data
        - ".headers"    = HTTP headers
        - ".status"     = HTTP request status code


- The method ".delete()"
    - Requires one (1) argument value
        - API endpoint (URL) for HTTP request DELETE

    - Returns an Axios object that contains the property
        - ".data"       = deleted data
        - ".headers"    = HTTP headers
        - ".status"     = HTTP request status code
