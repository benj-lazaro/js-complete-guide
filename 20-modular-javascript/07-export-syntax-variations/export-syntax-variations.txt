More Named Export Syntax Variations
-----------------------------------
- When importing more than one (1) Class, function, constant from a single source file
    - Import the exported name into the dependent file w/in the pair of "{ }"
    - Each exported name is separated by a ","
    
        import { <import_item>, <import_item>, ... } from "<file_path>/<file>.js";


- Imported items can be bundled into a single named object
    - The single object is referenced as "*"
    - Followed by the keyword "as"
    - Then an alias name for the bundled items

        import * as <object_name> from "<file_path>/<file>.js";


- The keyword "as"
    - Can also be used to assigning a new name to the exported items

        import {<exported_item> as <alias_name> } from "<file_path>/<file>.js";
    
    
    - IMPORTANT: The alias name will ONLY be relevant w/in the same file

    - Common use-case
        - Name clash (conflict) between a local constant & of the exported named item
