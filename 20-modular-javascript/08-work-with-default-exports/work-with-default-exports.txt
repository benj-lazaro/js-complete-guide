Working With Default Exports
----------------------------
- To set a default export (item)
    - Use the keyword "default" RIGHT AFTER the keyword "export"
        - The name of the item can be retained or removed
    
    - IMPORTANT: Each file is limited to ONLY one (1) default item to be exported


- The disadvantage of using a default export
    - Working w/ a team, anyone could assign & use their own preferred name
        - Ends up w/ a codebase having different names referring to the same default export item

    - Using a named import (export) over the default export is a better & safe choice
        - NOTE: The default export serves as an optional feature that can be used
        

- To import a default (export) item
    - After the keyword "import"
        - Assign ANY name to represent the default item
        - The name is NOT placed w/in the pair of "{ }"
        - NOTE: Omit the pair "{ }" is the source file ONLY contains the default (exported) item

        import <default_name> from "<file_path>/<file>.js";


- To import a default (export) item along w/ named items
    - After the keyword "import"
        - Assign ANY name to represent the default item
        - The name is NOT placed w/in the pair of "{ }"
        - Followed by a ","
        - Named items are placed w/in the pair of "{ }"

        import <default_name>, {<named_import_item>, ...} from "<file_path>/<file>.js";
