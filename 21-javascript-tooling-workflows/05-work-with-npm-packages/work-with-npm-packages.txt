Working With npm Packages
-------------------------
- To download & locally install a npm package as a "development dependency" of a project via npm

    npm install --save-dev <package_name>


- To know more about a npm package's installation process
    - Search online using the keywords "npm <package_name>"


- For every npm package installed:
    - The "package.json" file's "devDependencies" property gets updated w/
        - The installed package's name & version number

    - When installing packages for the 1st time
        - The file "package-lock.json" is created that
            - Contains information about the package & its dependencies

        - The folder "node_modules" is created that
            - Contains the package's files, its dependencies & dependencies of its dependencies

            - IMPORTANT: Do NOT TOUCH the code of any of these files

            - IMPORTANT: EXLUDE this folder when sharing the project                
                - INCLUDE the project's "package.json" file
            
                - Running the following npm command will install the npm packages used by the project
    
                    npm install
