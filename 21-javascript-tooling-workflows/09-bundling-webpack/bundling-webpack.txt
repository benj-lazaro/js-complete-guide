Bundling With Webpack
---------------------
- Webpack is a popular bundling tool
    - It also helps orchestrate a project's entire build workflow

    - It can be configured manually
        - By creating a file named "webpack.config.js", placed at the project's root folder 

        - File's contents will be read by Node.js & excute it
            - Based on the user-defined npm script on the project's "package.json" file

    - Inside the "webpack.config.js" file
        - The "module.export" is declared & assigned w/ a JavaScript object literal
            - The object literal contains information how Webpack will be configured

        - This allows the Webpack configuration to be exported outside of the file
            - Read & worked on by Node.js

        - Requires importing the built-in package "path" & function "require()" of Node.js
            - To point & resolve the absolute path of a project's entry point for Webpack

    - Create a new file named "webpack.config.js" 
        - Saved it at the project's root folder


    - Inside the file "webpack.config.js"
        - Create a global constant named "path"
            - Assign the built-in module "path" of Node.js as value
            - Call the built-in function "require()"
            - Pass "path" as argument value
            
            - NOTE: This imports the Node.js module "path"
                - This needed to resolve the absolute path of 
                    - The project's entry point needed by Webpack

        - Define "module.exports"
            - Assign an empty JavaScript object literal as value

            - NOTE: This will used to export the Webpack configuration that
                - Will be defined w/in the object literal outside to the file
                - To be read & worked on by Node.js

        - Inside the empty JavaScript object literal
            - Define the key named "entry"
                - Assign the path (relative to the config file) "./src/app.js" as value
                - NOTE: This specifies Webpack's entry point (input) to the project

            - Define the key named "output"
                - Assign an empty object literal as value 
                - NOTE: This specifies the Webpack's output point where the bundled files will be placed

            - Inside the object literal
                - Define the key named "filename"
                    - Assign "app.js" as value
                    - NOTE: This "app.js" will contain the bundled files by Webpack

                - Define the key "path"
                    - Assign "path.resolve(__dirname, "assets", "scripts")" as value
                    - NOTE: The "path" object method "resolve()" constructs & 
                        - Returns an absolute path of the "app.js" to be created

            - Save the changes
                - This file now contains a basic Webpack configuration

    
    - Open the file "package.json"
        - On the property "scripts"
            - After the script named "test", place a ","
            - Add a new script named "build"
            - Assign "webpack" as value

        - Save the changes
            - This creates a new npm script named "build"

            - Executing this script using "npm run build" 
                - Calls the package "webpack-cli" first then calls the package "webpack"

                - The package "webpack" searches for the file "webpack.config.js"
                    - Identifies the entry & output points
                    - Then work on bundiling the files w/in the folder "src"
                    - Outputs two (2) bundled files in the folder "assets/scripts"
