Bundling With Webpack
---------------------
- Webpack is a bundling tool that also help orchestrate
    - A project's entire build workflow
    

- Webpack can be configured manually
    - Creating a file named "webpack.config.js"
        - Placed at the project's root folder 

    - The contents of this file will be read & worked on by Node.js 

    - Reference (https://webpack.js.org/configuration)


- Inside the file "webpack.config.js"
    - Use "module.exports" to export the configuration outside of the file
        - Assign a JavaScript object literal as value

            module.exports = {
                // Webpack configuration
            };

    - This object literal will contain
        - Information on how Webpack will be configured

    - Inside the file "webpack.config.js"
        - Import the Node.js' built-in module "path"
            - Call the function "require()"
            - Pass "path" as argument value

        - Define "module.exports"
            - Assign an empty JavaScript object literal as value

        - Inside the JavaScript object literal
            - Define the key "entry"
                - Assign "./src/app.js" as value
                - NOTE: This specifies Webpack's entry (input) point

            - Define the key "output"
                - Assign an empty JavaScript object literal as value
                - NOTE: This specifies Webpack's output point

            - Inside the JavaScript object literal
                - Define the key "filename"
                    - Assign "app.js" as value
                    - NOTE: This "app.js" will contain the bundled code

                - Define the key "path"
                    - Assign "path.resolve(__dirname, "assets", "scripts")" as value
                    - NOTE: This method contructs (& returns) an absolute path

        - Save the changes
            - This file now contains a basic Webpack configuration
