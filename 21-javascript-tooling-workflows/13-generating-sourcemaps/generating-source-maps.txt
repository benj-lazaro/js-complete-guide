Generating Source Maps
----------------------
- On the current state of Webpack
    - Performing some debugging on a project's code via browser's "Developer Tools" (Dev Tools)
        - Clicking the "Sources" tab

        - The left-hand side panel displays a tree containing two (2) folders
            - localhost:8080
                - Contains the files & folders of Webpack's output point
                - Files contains the appended & "development mode" code of Webpack

            - <project_name>
                - Contains processed copy of the project's source files
                - Does NOT include the entry point file (i.e. "app.js")
                - Files contains minimal appended & "development mode" code of Webpack
                - Easy to read & debug BUT NOT ideal

                - PERSONAL NOTE: On Webpack 4, this folder was labeled as "webpack://"

        - For an ideal debugging experience
            - Enabling Webpack's source maps is needed


- To enable Webpack's source maps
    - Open Webpack's "webpack.config.js"

    - On the "module.exports"
        - Add a new key named "devtool"
            - Assign an empty array as value

        - Inside the empty array
            - Assign an object literal as an element

        - Inside the object literal
            - Assign a key named "type"
                - Assign the string value "javascript"

            - Assign the value "source-map"

        - NOTE: The type "source-map" is recommended choice 
            - For production builds w/ high quality source maps
            - Reference (https://webpack.js.org/configuration/devtool/#devtool)
            
        - PERSONAL NOTE: Using other source map types w/ Webpack 5
            - ONLY the "source-map" type generates the ".map" files

            module.exports = {
                mode: "development",
                entry: "./src/app.js",
                output: {
                    filename: "app.js",
                    path: path.resolve(__dirname, "assets", "scripts"),
                },
                devServer: {
                    static: {
                    directory: "./",
                    },
                },
                devtool: [{ type: "javascript", use: "source-map" }],
            };


    - Run the npm script "build" to generate the ".map" files

        npm run build


    - Run the npm script "build:dev" to host the bundled files

        npm run build:dev


    - PERSONAL NOTE: Unlike the lesson based on Webpack 4
        - Running the npm script "build:dev" does NOT generate the ".map" files

        - Observed that the package "webpack-dev-server" does NOT
            - Reflect implemented changes on the files' source maps

            - Requires terminating the current session

            - Run the npm scripts "build" & "build:dev" in sequence

                npm run build && npm run build:dev

            - Refresh the browser
                - Updates the source maps of the "Sources" tab


    - The "project_name" folder of the "Sources" tab
        - NOW includes a copy of the entry point file ("app.js")
        - Files contains minimal appended code of Webpack along w/ the original source code
        - Ideal for debugging the app's source on the browser
