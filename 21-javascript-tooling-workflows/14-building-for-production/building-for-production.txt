Building For Production
-----------------------
- To setup Webpack for "production" mode
    - Create a new configuration file named "webpack.config.prod.js"
        - Located at the project's root folder
        - Copy & paste the contents of the "webpack.config.js" file

    - In the "webpack.config.prod.js" file
        - Change the assigned value of the key "mode" to "production"

        - PERSONAL NOTE: The Webpack 4 source map type "cheap-source-map" does NOT work w/ Webpack 5
            - Webpack 5 recommends "source-map" for production use w/ high quality source maps
            
            - For maximum bundle performance, NOT setting the "devtool" key is the way to go


- Add a new npm script in the "package.json" file
    - On the property "scripts"
        - Add a new key named "build:prod"
        - Assign the value "webpack --config webpack.config.prod.js"
        - Save the changes

    - NOTE: The project has now two (2) workflows namely "development" & "production"


- Run the npm script for "production" build

    npm run build:prod

    - Webpack bundles the project's source files in "production" mode
    - Store the generated files w/in the sub-folder "assets/scripts/" w/ or w/out source maps


- Use the npm package "serve" to locally host the project app

    serve

    - Click the "Local" URL to launch the default browser
    - Browser loads the "production" grade app
