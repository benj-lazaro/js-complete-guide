Final Optimizations
-------------------
- Implementation of two (2) final optimizations
    - Cleaning Webpack's output entry for every "development" or "production" build"
        - Prevents the accumulation of files

    - Changing the filename of the "production" bundled files
        - Prevents the default behavior of browsers using old (cached) files
        - Forces client browsers to use the latest bundled "production" files

    - PERSONAL NOTE: This lesson based on Webpack 4
        - Requires installing the package "clean-webpack-plugin" as a development dependency

        - However, installing this package reports three (3) warnings
            - Triggered by deprecated dependencies namely "inflight", "rimraf" & "glob"

        - Webpack 5 has the capability of cleaning its own output entry
            - Everytime it bundles a project's files for "development" or "production" use

            - Requires add the key "clean" w/ the value of "true"
                - To BOTH "webpack.config.js" & "webpack.config.prod.js" files


- To implement the 1st final optimization of cleaning out old files
    - Open the file "webpack.config.js"
        - On the key "output"
            - Add the key "clean"
            - Assign the value "true"

            const path = require("path");

            module.exports = {
                mode: "development",
                entry: "./src/app.js",
                output: {
                    filename: "app.js",
                    path: path.resolve(__dirname, "assets", "scripts"),
                    clean: true,
                },
                devServer: {
                    static: {
                    directory: "./",
                    },
                },
                devtool: [{ type: "javascript", use: "source-map" }],
            };

        - Save the changes
    
        - Run the npm scripts for the "development" workflow

            npm run build && npm run build:dev

            - Click the generated URL to launch the default browser
            - Browser loads the "development" grade project
            - Previous bundled (i.e. development or product) & source map files deleted
            - Replaced w/ fresh "development" bundled files w/ source maps


    - Open the file "webpack.config.prod.js"
        - On the key "output"
            - Add the key "clean"
            - Assign the value "true"

            const path = require("path");

            module.exports = {
                mode: "production",
                entry: "./src/app.js",
                output: {
                    filename: "app.js",
                    path: path.resolve(__dirname, "assets", "scripts"),
                    clean: true,
                },
                devServer: {
                    static: {
                    directory: "./",
                    },
                },
                //   devtool: [{ type: "javascript", use: "source-map" }],
            };

        - Save the changes
    
        - Run the npm script for the "production" workflow

            npm run build:prod

            server

            - Click the generated Local URL to launch the default browser
                - Browser loads the "production" grade project

            - The "development" bundled files deleted
                - Replaced by "production" bundled files w/ NO source maps included


- To implement the 2nd final optimization of renaming "prodution" bundled files
    - Open the file "webpack.config.prod.js"
        - On the key "filename" w/in the "output"
            - Change the assigned value "app.js" to "[contenthash].js"

        - NOTE: This replaces the filenames of the generated bundled files w/ hash
            - On every "production" build

            const path = require("path");

            module.exports = {
                mode: "production",
                entry: "./src/app.js",
                output: {
                    filename: "[contenthash].js",
                    path: path.resolve(__dirname, "assets", "scripts"),
                    clean: true,
                },
                devServer: {
                    static: {
                    directory: "./",
                    },
                },
                //   devtool: [{ type: "javascript", use: "source-map" }],
            };

        - Save the changes

    - IMPORTANT: Requires to MANUALLY update the assigned value to the HTML element <script>
        - Using the dynamically generated filename after a "production" build
        - BEFORE uploading the project files to the production server
