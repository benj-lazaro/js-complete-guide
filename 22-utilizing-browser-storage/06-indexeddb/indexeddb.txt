Getting Started With IndexedDB
------------------------------
- To store data in the browser's IndexedDB storage


- On the practice code (app.js)
    - Rename "app.js" file to "cookies.js"
        - Copy the entire codebase


    - Create a new "app.js"
        - Paste the codebase
        - Remove cookies-related code


    - Create a global constant "dbRequest"
        - Assign "indexedDB.open()" as value

        - Pass the following argument values:
            - 1st = "StorageDummy" (database name)
            - 2nd = 1 (database version; 1 when creating a new database)

        - IMPORTANT: Returns an "IDBOpenRequest" object that is NOT promised-based
            - This also referered as a "database request"

        - If the database requested does NOT exists in IndexedDB
            - It is creates a new database based on the given name
            - Otherwise, grants access to an existing one


    - Access the global constant "dbRequest"
        - Chain the Event Listener ".onerror"
            - Assign an Anonymous function as value
        
        - On the Anonymous function
            - Define the parameter variable "event"

        - Inside the Anonymous function
            - Pass "Error!" as argument value to "console.log()"
            
        - NOTE: Triggered when the "database request" failed


    - Access the global constant "dbRequest
        - Chain the Event Listener ".onupgradeneeded"
            - Assign an Anonymous function as value
        
        - On the Anonymous function
            - Define the parameter variable "event"

        - Inside the Anonymous function
            - Create a local constant named "db"
                - Assign "event.target.result" as value
                - NOTE: Grants access to the database "StorageDummy"

            - Create a local constant "objStore"
                - Assign "db.createObjectStore()" as value

                - Pass the following argument values:
                    - 1st = "products"        (table name)
                    - 2nd = { keyPath: "id" } (configuration object)
        
                - NOTE: Creates & returns access to an Object Store (table)
                    - Configuration object defines the key (property) that is required
                    - To identify every stored object w/in the created Object Store

            - Access the local constant "objectStore"
                - Chain the property ".transaction"
                - Chain the Event Listener ".oncomplete"
                - Assign an Anonymous function as value
                - NOTE: Triggered when the creation of Object Store is completed

                - On the Anonymous function
                    - Define the parameter variable "event"

                - Inside the Anonymous function
                    - Access the local constant "db"

                    - Chain the method ".transaction()"
                        - Pass the arguments values:
                            - 1st = "products" (table name)
                            - 2nd = "readwrite" (transaction mode)
                            - NOTE: Configures the connection to the Object Store

                    - Chain the method ".objectStore()"
                        - Pass "products" (table name) as argument value
                        - NOTE: Grants direct access to the Object Store
                    
                    - Create a local constant named "productsStore" &
                        - Store the previous statement as value

            - Access local constant "productsStore"
                - Chain the method ".add()"

        - NOTE: Triggered when the "database request" succeeded


    - Save the changes
        - Load / Reload the browser
            - Launch the browser's Developer Tools
            - Click the "Application" table

        - On the left-hand side panel
            - Expand "IndexedDB"

        - Refresh page
            - The database "StorageDummy" is created
            
        - Expand "StorageDummy"
            - The table "products" is displayed

        - Click the Object Store "products" (table)
            - The stored items w/in the Object Store are displayed

        - NOTE: In the event that IndexedDB reported 0 Object Stores
            - Click "Delete database" button
                - Confirm deletion of the "StorageDummy"

            - Reload the web page again
