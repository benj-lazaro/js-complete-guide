More Time Complexities & Comparing Algorithms
---------------------------------------------
- Deriving the Time Complexity of the function "getMin2()"
    - Focus on the dynamic parts of the code


- On the practice code
    - The function "getMin2()" has two (2) dynamic parts
        - The outer "for" loop
        - The inner "for" loop


    - Based on the behavior of the implemented algorithm in the function
        - Like the function "getMin()"
            - The performance is dependent on the input size

        - Unlike the function "getMin()"
            - It has BOTH "for" loops iterate through ALL of the array elements

            - Passing an array of 100 elements
                - Each "for" loop executes 100 times
                - Both "for" loops will execute 10000 times

            - It is NOT growing linearly but quadratically instead

        - The algorithm has a "Quadratic Time Complexity"
            - Mathematically expressed as "O(n^2)"


    - The "Linear Time Complexity" of the function "getMin()" is much better than
        - The "Quadratic Time Complexity" of the function "getMin2()"
        
        - The algorithm used by function "getMin()"
            - Takes less time = better performance

        - The algorithm used by the function "getMin2()"
            - Takes twice longer = slow performance
